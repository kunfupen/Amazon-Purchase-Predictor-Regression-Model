# Analysis

This folder contains R Markdown notebooks for the Amazon purchase regression project.

## Files

- `knn_baseline_model.Rmd`: Baseline KNN regression workflow.
- `knn_recipe_model.Rmd`: KNN workflow with preprocessing recipe, interaction term, PCA, and tuning.
- `random_forest_model.Rmd`: Random forest regression workflow with preprocessing and resampling.

The notebooks expect `../data/train.csv` and `../data/test.csv`.
